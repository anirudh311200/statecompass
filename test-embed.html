Embed test moved to public/embed-test.html

Double-clicking an HTML file uses file://, and browsers block StateCompass iframes from that context — you will see “refused to connect” even though embeds work on real websites.

Run one of these instead:

  1. npx serve public → http://localhost:3000/embed-test.html
  2. npm run preview → /embed-test.html
  3. Production → statecompass.app/embed-test.html
